flowchart TD
    A([adapt_sort a, n]) --> B{n < 2?}
    B -- 是 --> B1[S1 直接返回
SmallBinaryInsert]
    B -- 否 --> C{n <= 32?}
    C -- 是 --> C1[S1 二分插入排序
SmallBinaryInsert]
    C -- 否 --> D[阶段A probe_order
O sqrt n 采样顺序结构]

    D --> E{采样一致且
全量确认已升序?}
    E -- 是 --> E1[S2 AlreadyAscending
直接返回]
    E -- 否 --> F{采样一致且
全量确认已降序?}
    F -- 是 --> F1[S3 ReverseToAscending
反转数组后返回]
    F -- 否 --> G{n <= 512 且
inv_rate <= 0.05?}
    G -- 是 --> G1[S1b SmallInsert
直接插入排序]
    G -- 否 --> H{类型 T 是整数?}

    H -- 否 --> I[通用键比较类分支]
    H -- 是 --> J[整数键分支]

    %% 通用键分支
    I --> I1{n > 512?}
    I1 -- 是 --> I2[probe_dup 测重复率]
    I1 -- 否 --> I3[不测重复率]
    I2 --> I4{dup_rate >= 0.20?}
    I3 --> I4
    I4 -- 是 --> I5[S6 Quick3Way 三路快排]
    I4 -- 否 --> I6{inv_rate <= 0.05?}
    I6 -- 是 --> I7[S7 MergeSorted 边界检测归并]
    I6 -- 否 --> I8[S8 IntroSort 内省快排]

    %% 整数键分支
    J --> J1[probe_range 测采样值域]
    J1 --> J2{n <= 512 且
sample_range+1 <= 2n?}
    J2 -- 是 --> J3[全量扫描真实 min/max]
    J3 --> J4{真实 k <= 8n?}
    J4 -- 是 --> J5[S4 CountingSort 计数排序]
    J4 -- 否 --> J6[S8 IntroSort 内省快排]

    J2 -- 否 --> K[cm.prepare 准备成本模型]
    K --> L[计算 k_est / e_count_est / scan_cost
判断是否值得全量扫描值域]
    L --> M{scan_worth?}
    M -- 是 --> M1[全量扫描 min/max
exact = true]
    M -- 否 --> M2[用采样值域
exact = false]
    M1 --> N[计算 k, bits, passes]
    M2 --> N

    N --> O[预测比较类成本 e_cmp]
    O --> P[预测计数成本 e_count]
    P --> Q[预测基数成本
e_radix16 / e_radix8 取较小者]
    Q --> R{值域类是否进入竞争?
e_count*MARGIN <= e_cmp
或 e_radix*RMARGIN <= e_cmp}

    R -- 否 --> S[落入比较类]
    R -- 是 --> T{计数 vs 基数
e_count*CMARGIN <= e_radix
且 e_count*MARGIN <= e_cmp?}
    T -- 是 --> T1[S4 CountingSort 计数排序]
    T -- 否 --> T2[S5 RadixLSD
按 radix_db 选 8/16 位]

    S --> S1{n > 512?}
    S1 -- 是 --> S2[probe_dup 测重复率]
    S1 -- 否 --> S3[不测重复率]
    S2 --> S4{dup_rate >= 0.20?}
    S3 --> S4
    S4 -- 是 --> S5[S6 Quick3Way 三路快排]
    S4 -- 否 --> S6{inv_rate <= 0.05?}
    S6 -- 是 --> S7[S7 MergeSorted 边界检测归并]
    S6 -- 否 --> S8[S8 IntroSort 内省快排]

五、关键判断节点速查表

节点条件走向
极小规模n <= 32S1 二分插入
已升序采样一致 + 全量确认S2 直通
已降序采样一致 + 全量确认S3 反转
小规模近似有序n <= 512 && inv_rate <= 0.05S1b 插入
小规模窄值域n <= 512 && sample_range+1 <= 2n扫描后计数或内省
整数键is_integral_v<T>进入值域类竞争
非整数键否则只能比较类
值域类胜出e_count*MARGIN <= e_cmp 或 e_radix*RMARGIN <= e_cmpS4 或 S5
计数胜基数e_count*CMARGIN <= e_radix 且计数总体裕度过关S4 计数
否则—S5 基数
比较类高重复dup_rate >= 0.20S6 三路快排
比较类近似有序inv_rate <= 0.05S7 归并
其他—S8 内省快排
说明：MARGIN = 1.30 为计数排序进入比较类的裕度；RMARGIN = 1.10 为基数排序裕度；CMARGIN = 1.15 为计数相对基数的不对称裕度。所有成本预测均由 CostModel 在启动时按本机实测标定。
